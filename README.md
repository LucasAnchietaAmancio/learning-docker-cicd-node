# API de Controle de Usuários

Uma API REST simples para gerenciar usuários em um banco de dados PostgreSQL, containerizada com Docker e pronta para CI/CD via GitHub Actions.

## 📋 Objetivos da Atividade

- ✅ Criar uma API REST que salva usuários em PostgreSQL
- ✅ Containerizar a aplicação com Docker
- ✅ Implementar testes automatizados com Jest
- ✅ Preparar para CI/CD com GitHub Actions
- ✅ Preparar para deployment em EC2

## 🗄️ Banco de Dados

### Credenciais Padrão

| Parâmetro | Valor |
|-----------|------|
| Usuário | postgres |
| Senha | postgres |
| Host | localhost (desenvolvimento) / instance-postgres (Docker) |
| Porta | 5432 |
| Banco | docker_api |

### Schema da Tabela `users`

```sql
CREATE TABLE users (
    id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT NOT NULL,
    address TEXT NOT NULL,
    uf VARCHAR(2) NOT NULL
);
```

## 📡 API REST

### Endpoints

#### GET `/`

Verifica se a API está online.

```bash
curl http://localhost:3001/
```

**Response (200):**
```
Hello World!
```

---

#### POST `/users`

Cria um novo usuário no banco de dados.

**Request:**
```bash
curl -X POST http://localhost:3001/users \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Lucas Silva",
    "email": "lucas@example.com",
    "address": "Rua 1, Bairro X, Cidade",
    "uf": "MT"
  }'
```

**Request Body:**
| Campo | Tipo | Validação |
|-------|------|-----------|
| name | string | Mínimo 3 caracteres |
| email | string | Formato válido (regex) |
| address | string | Mínimo 5 caracteres |
| uf | string | Exatamente 2 caracteres |

**Response (201 - Sucesso):**
```json
{
  "id": 1,
  "name": "Lucas Silva",
  "email": "lucas@example.com",
  "address": "Rua 1, Bairro X, Cidade",
  "uf": "mt"
}
```

**Response (400 - Erro de Validação):**
```json
{
  "error": "Email inválido"
}
```

## 🚀 Como Executar

### Pré-requisitos

- Docker e Docker CLI instalados
- Docker Daemon rodando
- (Opcional) PostgreSQL local se não usar Docker

### Passo 1: Clonar o Repositório

```bash
git clone <seu-repositorio>
cd atividade-docker-github-actions
```

---

### Passo 2: Criar Arquivo de Configuração

Copie o arquivo de exemplo:

```bash
cp .env.example .env
```

Verifique se as variáveis estão corretas:

```env
DB_USER=postgres
DB_HOST=instance-postgres
DB_NAME=docker_api
DB_PASSWORD=postgres
DB_PORT=5432
```

> **Nota:** O `DB_HOST` deve ser `instance-postgres` (nome do container) quando rodar via Docker.

---

### Passo 3: Criar Rede Docker (Primeira Vez)

Os containers precisam estar na mesma rede para se comunicarem:

```bash
docker network create api-network
```

---

### Passo 4: Iniciar Container PostgreSQL

```bash
docker run \
  --name instance-postgres \
  --network api-network \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=docker_api \
  -p 5432:5432 \
  -d postgres:latest
```

Aguarde alguns segundos para o PostgreSQL inicializar:

```bash
docker logs -f instance-postgres
```

Você verá uma mensagem como:
```
database system is ready to accept connections
```

---

### Passo 5: Criar Tabela de Usuários

Acesse o PostgreSQL dentro do container:

```bash
docker exec -it instance-postgres psql -U postgres -d docker_api
```

No prompt `docker_api=#`, execute:

```sql
CREATE TABLE users (
    id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT NOT NULL,
    address TEXT NOT NULL,
    uf VARCHAR(2) NOT NULL
);
```

Saia do psql:

```
\q
```

---

### Passo 6: Buildar Imagem da Aplicação

```bash
docker build -t api-cadastro .
```

Verifique se a imagem foi criada:

```bash
docker images | grep api-cadastro
```

---

### Passo 7: Executar Container da Aplicação

```bash
docker run \
  --name api-docker-ci \
  --network api-network \
  --env-file .env \
  -p 3001:3001 \
  -d api-cadastro
```

---

### Passo 8: Verificar Logs da Aplicação

```bash
docker logs -f api-docker-ci
```

Você deve ver:
```
[DB] Conexão com PostgreSQL estabelecida com sucesso!
```
